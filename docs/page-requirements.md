# 页面要求

依据用户在「检查 EBCTFCodeBox 工具」会话中的明确要求，以及 2026-11-07 当前会话的补充。较新的要求优先。

## 当前框架

- React + TypeScript，页面和公共组件分别维护；CLI 与网页共用核心模块。
- 只使用简体中文，移除语言入口和多语言基础设施。
- 侧栏默认折叠，只保留一把梭、字符显示器、图形编码查询、快速换算四个导航入口。
- 侧栏底部只保留 GitHub 与日夜主题切换；关于、环境、插件、更新入口不保留。
- 展开和折叠使用同一套图标尺寸、描边和对齐规则。窄屏展开覆盖内容，不挤窄工作区。
- 首页占满可用区域，左侧输入，右侧结果；没有顶部应用栏、首页大标题或右侧原文卡。
- 延续目标标签、密钥、输入区和结果区的位置关系；控件左右边界对齐。
- 使用紧凑字号、适度行距、细线边框、小圆角和系统字体。CyberChef 只作为字体大小、行距和排版密度参考，禁止复制其代码、资源、组件与页面结构。
- 亮色和暗色使用同一套组件与布局。
- 当前只开放基础页面交互；业务功能显示真实的暂未开放状态。

## 后续业务接入时的验收约束

以下是历史会话已明确提出的行为要求，不属于当前算法实现范围：

- 解码结果边运行边显示，稳定增量更新，保留已展开状态，避免闪烁。
- 进度与暂停、终止控制在结果区顶部；滚动结果时仍可访问。
- 用户启用的目标命中优先展示；区分字面与正则规则。
- 启发式分数不标作真实概率，命中格式不等于验证了正确答案。
- 保留可复现的处理链、参数、未消费尾部和运行受限状态。
- 明确区分输入不适用、参数缺失、无命中和程序异常。

## 字体调查

2026-11-07 只读核对 CyberChef 上游默认主题：

- 界面使用系统字体栈；Windows 优先 Segoe UI，中文依赖系统字体回退。
- 编辑区使用系统等宽字体栈；Windows 通常使用 Consolas。
- 正文默认字号 14px、行高 20px，辅助文字 13px。
- 本项目仅参考上述排版参数，不下载其字体文件或复制 CSS。
- 来源：[CyberChef 默认主题](https://github.com/gchq/CyberChef/blob/master/src/web/stylesheets/themes/_classic.css)。
